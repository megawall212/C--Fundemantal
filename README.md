# 🖥️ Programming Fundamentals 2 (C++)

This repository contains most of my code from **COP3503C (Programming Fundamentals 2)** at the University of Florida, written in **C++**. It includes **all labs (1–7) and projects (1–3)**.  
The course instructor was **Tima Tavassoli**, and I completed this course in **Spring 2025** as a freshman.

---

## 📝 Labs

### Lab 1
- **Part A:** 🌡️ Basic input/output and arithmetic operations (temperature conversion)  
- **Part B:** 💰 Calculating sales tax for an item  
- **Part C:** 📅 Computing the number of days between two dates  

### Lab 2
- **Part A:** 🔺 Classifying triangles based on side lengths  
- **Part B:** 💸 Income tax calculation using 2023 federal tax brackets  
- **Part C:** 🌡️ Improved temperature converter supporting Celsius, Fahrenheit, and Kelvin  

### Lab 3
- 🧮 Menu-driven calculator supporting:
  - Addition ➕
  - Subtraction ➖
  - Multiplication ✖️
  - Division ➗
  - Exponentiation ⬆️
  - Logarithms 🔢
  - Displaying average 📊  

### Lab 4
- 🔢 **Fibonacci sequence generator**  
- 🔍 **Prime number checker**  
- 🧩 **Prime factorization of a number**  

### Lab 5
- 💻 Menu-driven program for:
  - Decoding hexadecimal 🔢
  - Decoding binary 0️⃣1️⃣
  - Converting binary to hexadecimal 🔀  

### Lab 6
- 🎮 **Connect Four game** using a 2D board  
- Handles player turns, inserting chips, and checking for a winner 🏆  

### Lab 7
- 📚 **Student grade calculator** using imported course data  
- Computes weighted scores for assignments and prints total grades 🏅

## 🚀 Projects

### 🃏 Project 1 – Blackjack Game
- Text-based **Blackjack game**  
- Options for drawing cards 🂡, holding hand ✋, and statistics tracking 📊  

### 🖼️ Project 2 – RLE Image Encoder
- **Run-Length Encoding (RLE)** for images  
- Menu-driven program to load, encode, decode, and display images 🖌️  

### 🎲 Final Project – Sudoku Game
- GUI-based **Sudoku game using Pygame**  
- Supports multiple difficulties 🌟, resetting the board 🔄, and tracking game state ✅
